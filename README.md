Mapping the dynamic pH heterogeneity of the secretory pathway
The secretory pathway is a tightly regulated series of organelles, each with a distinct pH that is essential for protein modification, sorting, and transport. 
Dysregulation of this pH gradient is associated with many diseases, from cancer to congenital disorders. 
A recent study used Fluorescence Lifetime Imaging (FLIM) to measure these pH values [1], but the data's full potential to reveal heterogeneous pH micro-environments 
and dynamic cellular responses remain not yet exploited. 

This project will re-analyse this FLIM data using non-negative matrix factorization (NMF) [2] to move beyond simple fitting. 
This computational approach will decompose the data into biochemically distinct components, each representing a unique pH state within the cell. 
This will involve first defining the fundamental pH states that characterize key organelles like the ER and Golgi. 

We will then investigate how these states are spatially organized within organelles and quantify how they are disrupted by pharmacological perturbations. 
Finally, we will model the dynamic sequence of pH changes experienced by a trafficking cargo protein to understand the temporal progression through these distinct 
biochemical environments. By creating a high-resolution map of the secretory pathway's pH heterogeneity, this project will provide new insights into the regulation 
of intracellular trafficking.
